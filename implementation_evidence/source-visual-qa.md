# Chunk 3 원문 시각 검증

합성 원문 **26개, 총 40페이지·슬라이드**를 실제 렌더링하고 모든 이미지에서 문장·표·합성 표시·잘림·겹침을 확인했습니다. 최종 파일의 SHA-256은 `chunk03-source-visual-qa.json`에 기록했습니다.

| 형식 | 원문 파일 | 확인 페이지·슬라이드 | 결과 |
|---|---:|---:|---|
| DOCX | 20 | 21 | 통과 |
| PDF | 3 | 9 | 통과 |
| PPTX | 3 | 10 | 통과 |

기존 ns/cd/lm 12개 원문과 심화 Northstar(nb)·제조업(mf) 14개 원문을 포함합니다. DOCX는 지정 렌더러와 LibreOffice, PPTX는 LibreOffice, PDF·슬라이드 이미지는 Poppler로 확인했습니다. 원문 변경 시 변경된 파일을 다시 렌더링하고 확인했습니다.

초기 PDF의 Helvetica 대체 글꼴에서 발생한 글자 간격 겹침은 Courier로 수정했습니다. DOCX 기본 제목 테두리와 색상 잔여물을 정리했고, 제조업 재무제표의 마지막 한 행만 별도 페이지로 넘어가던 문제는 재무상태표 전체를 두 번째 페이지에 배치하여 수정했습니다.

Windows의 Microsoft Word·PowerPoint에서는 실행하지 않았습니다. 이 검사는 레이아웃과 가독성의 검증이며 재무 Gold에 대한 독립 전문가 평가나 LLM 모델 성능 측정은 아닙니다. 렌더링 중간 이미지는 전달 ZIP에 포함하지 않습니다.
