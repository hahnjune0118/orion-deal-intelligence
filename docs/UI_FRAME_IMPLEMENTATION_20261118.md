# Orion 공통 화면 틀 적용

기준: `UI_FRAME_BLUEPRINT_20261118.md` / 작업 브랜치: `feature/korean-ui`

## 적용 내용

- 투자 대상·업무 관점·분석 기간을 왼쪽 상단으로 이동했다. 기존 컨트롤 ID와 저장된 재무 조서를 그대로 사용한다.
- 질문·증빙 보조 도구를 초기 설정 아래에 배치했다. 도구 목록만 펼쳐지고 내부 스크롤하며 8단계 업무 메뉴는 유지한다.
- 단계 이동은 왼쪽 메뉴 하나로 통일했다. 재무 분석 내부의 6개 분석 탭과 항목 사이의 문맥 이동 링크는 유지했다.
- 공통 제목·상태·하위 도구줄·본문 슬롯을 도입했다. 보조 도구에는 재무 기간 필터가 적용되지 않음을 표시한다.
- 패널 접기 버튼·콜백·접힘 스타일을 제거했다. 오른쪽은 위 상세/편집과 아래 자료 목록을 약 60:40으로 항상 표시한다.
- 원문 문서와 별도 재무 원천표를 구분하고 검색·형식 필터·버전·선택 표시·다운로드를 연결했다. 회사 변경 시 필터와 선택 자료를 새 프로젝트에 맞춘다.
- 자료 목록에서 원문 또는 재무 원천표를 선택해도 중앙의 분석 페이지는 바뀌지 않는다. 선택 재무 원천 다운로드는 서버에서 확인한 원본 CSV 바이트를 사용한다.
- 미저장 입력을 둔 채 회사·관점·기간·업무 화면을 바꿀 때 확인한다. 취소하면 원래 입력을 유지하며 저장 후 관점을 바꿔도 조서는 유지된다.
- 화면 틀 치수·스크롤은 `zzz_uniform.css` 한곳에서 관리한다. 이전 스타일 파일에서 같은 틀을 덮어쓰던 규칙을 제거했다.
- 데스크톱은 패널 내부에서 스크롤한다. 1024px 이하에서는 같은 순서의 작은 화면용 구조로 바꾸고 오른쪽 상세·자료를 중앙 아래에 상시 표시한다.

## 기존 시각화·표 보존

`visuals.py`를 변경하지 않았다. `layout.py`와 `fdd_workspace.py`의 차트 생성·그래프·표·워터폴·지표·시각화 호출은 변경 전후 AST 비교로 동일함을 확인한다. 시각화의 데이터·색상·점수 계산을 수정하지 않는다. 차트는 기존 반응형 동작으로 새 중앙 폭에 맞춰 그려지며, 넓은 표는 기존 내부 가로 스크롤로 열을 확인한다.

화면 관련 파일 밖의 기존 추적 파일은 SHA256으로 비교한다. 원본 문서·재무팩·분석 엔진·데이터 계약은 변경 대상이 아니다.

## 확인 자료

- 변경 전: `build/frame-blueprint-audit/`의 41개 상태 측정 및 17개 화면 캡처.
- 변경 후: `build/frame-implementation/acceptance/`의 화면별 캡처와 해상도별 `*-geometry.json`.
- 브라우저 검사: 1280×800, 1440×900, 1920×1080, 2560×1440에서 17개 화면의 경계와 본문 시작점을 비교한다. 내부 스크롤 전후 편차는 1px 이내다.
- 1920px에서 8단계 × PE/IB/Big 4를 점검하고 4개 크기에서 재무 분석 6개 탭의 그래프 표시를 확인한다.
- 1024/720/390px에서 문서 가로 넘침과 상세·자료 목록 표시를 확인한다.
- 원본 Word·CSV 다운로드, 질문 초안·증빙 승인, 대사·조정·검토·Excel/보고서 산출은 기존 브라우저 검사로 확인한다.
- 자료 검색 유지, 원문/재무 원천 선택, 회사 간 자료 분리, 취소한 회사 변경과 저장 후 관점 변경을 추가 검사한다.
- 실행 결과와 보존 확인은 `build/frame-implementation/verification.json`에 기록한다.

## 아이콘과 운영 범위

공식 파일 형식 SVG를 로컬 제공한다. PDF에는 Adobe 앱 로고 대신 Microsoft Fluent UI의 PDF 파일 아이콘을 적용했다. 상세 출처와 이유는 [파일 아이콘 기록](FILE_TYPE_ICONS.md)에 있다.

현재의 세션 기반 저장·합성 자료 검증·직접 입력 기능 범위는 그대로다. 이 화면 개편이 서버 영구 저장, 인증된 역할 권한, 자동 원장 추출 또는 실제 AI 분석을 추가하는 것은 아니다.

## 검증 결과

전체 웹·스모크·Chromium 검사 **101개가 통과**했다. 마지막 자료 분류/로딩 보정 후 자료·미저장 입력 검사 2개, 작은 화면 설정 정렬 보정 후 17개 화면과 1024/720/390px를 포함하는 검사 1개를 추가 통과했다. 추가 검사는 전체 검사와 중복된다.

4개 데스크톱 크기 × 17개 화면의 공통 경계와 본문 슬롯 시작점 최대 편차는 **0px**였다. 보호 대상 추적 파일 **709개**, 기존 `visuals.py`와 차트·표·지표 생성 호출의 보존을 확인했다. 의존성 검사·구문 검사·공백 검사도 통과했다.
