# 익명화 딜 사례를 여는 방법

기본 앱 `http://127.0.0.1:8050`의 왼쪽 **등록된 사례 연구**에서 사례를 선택하고 **사례 열기·이어하기**를 누른다. `?case=사례-ID` 링크로도 열 수 있다. 이미 열었던 사례는 검토 이력을 유지하며 이어서 연다.

현재 이 PC에는 물류 플랫폼 인수 사례 `logistics-alpha`와 주류 브랜드 자산 인수 사례 `spirits-beta`가 등록되어 있다. 각 사례의 파일·질문·가정·검토 이력은 별도 프로젝트로 유지한다. 두 번째 사례는 회사 제공 자료 6개와 모델·IM 5개를 구분하고, 월별 매출 대사·실적/계획 경계·로열티·취득 권리·운전자금·회수 구조를 검토한다. 원본 모델의 오류·미계산은 보정하지 않는다.

사례 파일은 이 PC의 `.local/orion-rules/case-studies/`에 두고, 프로젝트·검토 이력은 기존 로컬 DB에 저장한다. 실제 딜 텍스트·수치와 원본 경로·마스킹 사전은 Git에 포함하지 않는다. 서버가 제공하는 파일은 마스킹 텍스트이며 원본 Excel·Word·PowerPoint 바이너리나 로고를 제공하지 않는다.

## 5단계에서 확인할 것

1. **투자자료 분석:** 거래 개요, 시점별 거래안, 자금흐름 워터폴, 지분 민감도, 우선 검증 쟁점을 확인한다. 오른쪽 자료 목록은 모든 단계에서 유지된다.
2. **투자 가설 생성:** 사례 구성자가 채택한 검증 가설과 반대 가설을 수정한다. 채택은 실사 결론이나 투자 승인이 아니다.
3. **실사 질문 생성:** 사례별 질문 초안·요청 자료·판정 기준을 검토한다. 조건별 후속 질문은 부모 질문의 검토 결과에 따라 열린다.
4. **중요도 평가:** 처음에는 확률·EIG·EVSI가 미설정이다. **편집 가능한 실습 가정 적용**을 누르면 사전확률·우도·효용·확보 비용·지연 비용 시나리오로 계산한다. 실제 자료에서 추정한 확률이나 실제 실사 견적이 아니며 개별 상세에서 수정할 수 있다.
5. **새 증거 반영:** 현재 자료 확인 예시와 **가상 후속 증거** 예시가 입력을 채운다. 자동 적용하지 않으며 원문·이유를 검토한 뒤 미리보기·적용·반려를 선택한다. 가상 예시는 화면과 검토 기록에 실습용으로 표시한다.

실제 증거를 평가할 때는 기존의 실습 확률·효용 가정이 적합한지 먼저 검토한다. 원문 추출·질문 상태·확률 반영·거래 승인 상태를 같은 의미로 취급하지 않는다.

## 자료의 범위

- Excel: 셀 좌표·수식·저장 계산값을 텍스트로 보존한다. 원본을 재계산하거나 수정하지 않는다. 저장 계산값이 없는 수식은 미확인으로 남겨야 한다.
- Word: 본문 문단·표 행의 위치와 텍스트를 사용한다.
- PowerPoint: 슬라이드별 텍스트를 사용한다. 이미지·로고·발표자 노트·임베디드 차트 워크북은 별도 검증 없이 재현하지 않는다.
- 형식 아이콘은 원본 자료 종류를 뜻한다. 내려받기는 **마스킹 텍스트 다운로드**이며 재작성된 Office 파일이 아니다.
- 재무 수치·단위·기간·업종은 유지한다. 서로 다른 버전·범위의 수치는 자동으로 하나의 확정치로 합치지 않는다. 자료 속 법령·상장 기준·미래 일정 등도 당시 문서 기재이며 현재 유효성을 별도로 검증한 판단이 아니다.

## 사례 패키지와 검증

`orion-anonymized-case-1` 형식의 패키지에는 별칭 파일명, 마스킹 원문 구간, 위치, 텍스트 해시, 가설·질문과 근거 연결, 시점별 조건, 선택적 실습 가정을 포함한다. 서버는 경로 이탈·텍스트 해시 불일치·근거 ID 누락·초기 확률 주입을 거절한다. 모든 파일과 프로젝트를 하나의 트랜잭션으로 등록한다.

원본은 별도 로컬 자료로 유지하며, 원본 경로·실명 대응표·추출 전 텍스트를 웹 응답에 포함하지 않는다. 이 정도 마스킹은 수치·기간 등으로 재식별할 가능성까지 완전히 제거하는 익명화를 뜻하지 않는다.
