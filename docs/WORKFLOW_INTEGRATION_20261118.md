# FDD 8단계 통합

왼쪽의 업무 단계는 8개로 통일하고 질문·증빙 도구 메뉴를 제거했다. 각 단계의 하위 화면에서 기존 기능과 시각화를 그대로 사용한다.

| 단계 | 하위 화면 |
|---|---|
|1. 거래 개요·실사 범위|범위·거래 배경, 투자 가설, 증빙 개요|
|2. 자료실·자료 요청|자료 요청, 원문·증빙 탐색|
|3. 재무 데이터·대사|대사, 원천 확인, 쟁점 연결|
|4. 재무 실사 분석|기존 6개 재무 분석 탭, 고급 분석 Bayesian/EIG|
|5. 쟁점·실사 질문·경영진 Q&A|쟁점과 답변, 질문 검토·편집, 중요도|
|6. 조정사항·거래 영향|기존 조정·거래 영향 분석|
|7. 작성·검토 관리|조서 작성·검토, 증빙 승인·반려|
|8. 보고서·산출물|FDD 보고서·데이터북, 질문표·예비 심사 메모, 참고 수동 조서|

## 연결 방법

질문 편집 화면에서 오른쪽의 연결할 쟁점을 선택하고 ‘이 질문을 쟁점에 연결’을 누른다. 선택하지 않으면 새 쟁점을 등록한다. 동일 질문을 다시 연결하면 기존 쟁점을 연다. 재무 대사·분석 항목도 선택 후 같은 방식으로 연결한다. 한 쟁점에 질문과 재무 원천을 함께 연결할 수 있다.

쟁점에서는 기존 자료 요청·조정 선택 필드로 요청과 조정을 연결한다. 오른쪽 상세에는 관련 질문·발견 원천·요청·조정·쟁점 상태·조서 상태·최근 이력이 표시된다. ‘원본 질문·증빙 확인’으로 원래 질문에 돌아갈 수 있다.

질문 ID와 연결 당시 증빙 스냅샷, 재무 원천 참조는 저장·편집 후에도 유지하며 Excel 및 Markdown 보고서에 포함한다. 원본 질문·자료를 복제하거나 숫자를 추출한 것으로 취급하지 않는다. 질문 제목은 저장된 검토 초안이 있으면 그 내용을 사용한다.

증빙 승인·조정 분석 반영·조서 검토 확정은 별도 동작이다. 연결 변경은 조서 검토를 다시 요구하며 공식 증빙 승인이나 공식 점수를 바꾸지 않는다. 금액 영향은 사람이 검토해 입력한다. 세션 저장 범위는 기존과 같다.

기존 차트·표 생성 코드는 보존했다. 공통 프레임·상시 자료 목록도 유지한다. 원문과 별도 합성 재무팩의 분류는 그대로다.

검증 기록과 화면 캡처: build/workflow-unification/.

## 검증 결과

전체 검사에서 100개가 통과하고 2개가 실패한 뒤, 수정한 반응형·통합 연결 검사 2개와 조서 검사 13개를 재실행해 15개 모두 통과했다. 따라서 서로 다른 검사 102개가 통과했으며 재실행 13개는 중복이다. 기존 시각화 모듈과 차트·표 생성 호출 보존도 확인했다.

현재 연결 모델은 쟁점마다 질문 참조 1건·발견 원천 참조 1건, 기존 자료 요청·조정 각 1건이다. 이미 연결된 같은 질문이나 원천은 쟁점을 중복 생성하지 않고 기존 쟁점으로 이동한다. 서로 다른 원문 주장팩과 재무팩 사이의 연결을 자동 사실 검증으로 간주하지 않는다.
