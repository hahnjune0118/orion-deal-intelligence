## 5단계 사용법

| 단계 | 담당자 작업 | 표시되는 결과 |
|---|---|---|
| 1. 투자자료 분석 | 기업·검토 기간으로 프로젝트 생성 → 자료 등록 → 자료 분석 | 처리 범위, 검출 주제, 원문 숫자·기간 표현, 원문 검색 |
| 2. 투자 가설 생성 | 가설·반대 가설의 범위와 기간을 검토·수정 → 확정 | 근거가 연결된 가설 카드. 사전확률은 선택 입력 |
| 3. 실사 질문 생성 | 확정 가설로 질문 구성 → 질문·요청 자료·판정 기준 수정 | 단일 질문 목록. 라이브러리에 없는 질문 직접 추가 |
| 4. 중요도 평가 | 중요도·확보 가능성·필수 여부를 검토. 필요시 우도·효용 가정 설정 | 다음 질문 3개, 전체 추천 순서, 점수 구성·EIG·EVSI |
| 5. 새 증거 반영 | 원문 또는 답변 연결 → 지지/반박/불충분/재개 선택 → 검토 이유 → 미리보기 → 적용/반려 | 가설 확률·질문 상태·후속 질문·추천의 전후 비교. 철회·과거 버전 비교 |

5단계 후 4단계로 돌아가 다음 질문을 선택한다. 같은 ID의 기존 질문·수정·증거를 보존하며 생성 버튼을 누를 때마다 덮어쓰지 않는다.

왼쪽에 프로젝트와 5단계만 배치했다. 오른쪽 위에는 근거·평가 상세, 아래에는 모든 단계에서 보이는 자료 목록이 있다. 데스크톱에서 단계 전환 시 공통 패널의 위치·폭·높이를 유지하며 원문은 16px로 표시한다. 작은 화면은 세로 배치로 전환한다.

## 질문 라이브러리와 검색

- 주제: 매출 정의·기간 귀속, 고객 집중·계약 지속성, 매출–수금 연결, 반복매출, 이익·원가, 성장 계획, 설비투자.
- 기본 3개 주제에 자료 표현에 맞는 주제 최대 2개를 추가한다. 업종 선택만으로 ARR·NRR 질문을 강제하지 않는다.
- 초기 질문과 지지/반박 결과별 후속 질문을 구분한다. 예: 반복매출 정의 확인 → 지지 시 고객 코호트 대사, 반박 시 제외 계약을 반영한 재산정 질문.
- BM25 검색은 금융 동의어·한국어 부분 토큰을 포함하여 현재 프로젝트의 원문 구간만 대상으로 한다. 문서명·버전·페이지/문단/슬라이드·문자 위치와 원본 해시를 보관한다.
- 숫자는 원문 표현으로 추출한다. 자동 재무 수치 확정·표 재구성·공백/상충의 자동 사실 판정은 하지 않는다. 관련 표현 미검출을 자료 부재나 위험의 증명으로 취급하지 않는다.
- 생성형 RAG의 의미 검색·자유 생성은 구현 범위에서 제외했다. 현재 방식은 원문 검색과 규칙 템플릿 연결이며 AI가 새 내용을 추론한 것으로 표시하지 않는다.

라이브러리는 `src/orion/rules/library.py`에 있다. 새 검증 과제는 주제, 질문, 요청 자료, 판정 기준, 중요도, 부모 질문·판정 조건으로 추가한다. 회사별 새 위험은 화면에서 직접 질문으로 추가할 수 있다.

## 확률과 질문 가치

### Bayesian 반영

실제 프로젝트에는 자동으로 사전확률이나 우도를 부여하지 않는다. 담당자가 가설의 사전확률과 근거, 질문별 `P(지지|H)`·`P(지지|반대 H)`와 출처를 입력해야 한다. 부정 결과는 해당 우도의 여집합으로 계산한다.

`P(H|지지) = P(H)×P(지지|H) / [P(H)×P(지지|H)+(1−P(H))×P(지지|반대 H)]`

이는 입력한 가정의 계산 결과이며 투자 성공확률·경험적으로 검증된 예측치가 아니다. 합성 사례의 `0.3, 0.8, 0.2`는 계산 확인용이며 실제 프로젝트에 복사하지 않는다.

- 미리보기는 저장하지 않는다. 원문·판정 기준을 확인한 뒤 적용해야 한다.
- 동일 원문은 같은 가설에 중복 적용하지 않는다. 같은 의존 그룹은 확률을 중복 곱하지 않는다.
- 다른 그룹의 추가 증거도 독립성을 명시적으로 확인해야 확률을 추가 반영한다. 계약·검수·수금을 무조건 독립 사건으로 취급하지 않는다.
- 확률 반영이 보류돼도 담당자가 검토한 질문 상태와 답변은 별도로 남는다. 화면에 보류 이유를 표시한다.
- 불충분·질문 재개는 확률을 유지한다. 반려는 추천을 바꾸지 않는다. 철회하면 남은 승인 증거를 재생한다.
- 과거 증거는 적용 당시 우도를 보관한다. 현재 우도 수정은 앞으로 적용할 증거에 영향을 준다. 사전확률 변경은 새 사전확률에서 승인 증거를 재생하며 이전 스냅샷을 남긴다.

### EIG와 추천

EIG는 질문 전에 기대하는 엔트로피 감소이며 단위는 bits다. 사전확률·우도가 없으면 `미계산`이다. 필수 질문을 먼저 둔 뒤 다음 가중합으로 순서를 정한다.

- 중요도 35%: 담당자 1~5 평가를 0~1로 정규화
- 증빙 공백 25%: 미해결 질문을 우선하며 관련 원문 존재를 검증 완료로 취급하지 않음
- EIG 25%: 이진 가설의 최대 정보량 1bit 기준
- 확보 가능성 15%: 담당자 1~5 평가를 0~1로 정규화

EIG가 없으면 나머지 75%를 재정규화한다. 라이브러리 기본값은 회사의 실측 값이 아닌 평가 틀이다. 우선순위 미검토 또는 EIG 미설정 상태를 **잠정 추천**으로 표시한다. EVSI 금액과 EIG를 더하지 않는다.

### EVSI

선택한 질문의 상세에서 두 행동(진행/보류)×두 상태(H/반대 H)의 효용과 단위·출처, 질문 확보 비용, 별도 지연 비용을 입력한다. EVSI는 답변별 최적 행동의 기대효용과 현재 최적 기대효용의 차이다. EVSI, 비용 차감 후 순효용, EVPI 상한을 따로 표시한다. 의사결정이 달라지지 않으면 정보량이 있어도 EVSI는 0일 수 있다.

합성 예: 사전확률 0.3, 우도 0.8/0.2, 진행 효용 100/−100, 보류 0/0이면 지지 후 확률은 약 63.16%, EIG 약 0.2361bits, EVSI 10점이다. 확보 비용 5점 차감 후 5점이며 지연 비용 2점까지 입력하면 3점이다.

## 지원 파일과 한도

| 형식 | 처리 |
|---|---|
| PDF | 텍스트 추출과 실제 페이지 번호. 스캔 페이지는 검토 필요. 암호화 파일은 해제 사본 필요 |
| DOCX | 본문 문단·표 셀의 원문 위치. 지원하지 않는 머리말·각주·복잡한 요소는 경고 |
| PPTX | 슬라이드·도형·문단·표 위치. 이미지 텍스트·발표자 노트 등은 경고 |
| TXT·MD·CSV | UTF-8 텍스트의 원래 행 번호. CSV 수식 실행·회계 모델 해석은 없음 |
| XLSX | 셀·수식·저장된 계산값·표시 형식 추출. 입력 양식 관측치와 직접 등록 셀은 검토 후 동일 기준 대사. 수식 재계산 없음 |
| 이미지·스캔 OCR | 자동 해석 미지원. 텍스트 사본 또는 직접 원본 확인 필요 |

파일당 10MB, PDF 최대 600페이지, 추출 텍스트 150만 자, 처리 시간 40초, 프로젝트당 자료 30개·추출 텍스트 400만 자다. DOCX/PPTX는 기존 보안 파서의 구조·확장 크기·슬라이드 수 제한도 적용한다. 한도 초과 시 일부만 읽고 완료로 표시하지 않는다. 원문 조각은 최대 1,200자로 나누며 원본 파일은 온전히 보관한다. 추출 완료는 재무 검증 완료가 아니다.
