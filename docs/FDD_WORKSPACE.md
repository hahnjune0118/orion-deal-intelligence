# Orion FDD 작업 공간

IB·Big 4·PE의 재무 실사 업무를 지원하는 로컬 검증 버전이다. 질문 생성 절차를 주 메뉴로 쓰던 화면을 거래별 재무 분석·근거·판단·검토·산출물 중심으로 바꿨다. 기존 점수 엔진, 질문 ID, 증빙 승인, 원문 인용은 별도 보조 도구로 유지한다.

## 메뉴와 실제 작업

| 메뉴 | 수행 가능한 작업 |
|---|---|
| 1. Deal 개요·실사 범위 | 법인·사업·거래 구조·관점·기간·기준일·회계기준·통화·단위·제한사항 저장. Big 4 / PE / IB 기본 보기 |
| 2. 자료실·자료 요청 | 요청 ID·담당자·기한·수령/보완 상태·원천 버전·조서 연결 관리. 재무 CSV 템플릿 및 검증 입력 |
| 3. 재무 데이터·대사 | 원장 계정·차대변 부호 매핑. 관리손익 ↔ 시산표 ↔ 매핑 원장 ↔ 연간 재무제표 비교. 원차이·대사 조정·잔여 차이 구분 |
| 4. 재무 실사 분석 | 과거 실적 / QoE / NWC / 순차입금 / 현금흐름·CAPEX / 전망을 병행 분석 |
| 5. 쟁점·경영진 Q&A | 발견사항·금액 영향·추가 요청·관련 조정·경영진 답변·실사팀 결론 기록 |
| 6. 조정사항·거래 영향 | 조정 후보·분석 반영·제외와 경영진 합의를 별도 기록. Peg 후보 선택. EV 입력 시나리오와 Equity bridge |
| 7. 작성·검토 관리 | 작성 제출, 다른 이름의 검토자 기록, 검토 의견·해소, 변경 이력, 확정 해제 |
| 8. 보고서·산출물 | 같은 계산 결과의 Excel 데이터북·Markdown FDD 검토 보고서·원천 CSV 묶음 |

왼쪽 메뉴와 중앙 단계 버튼은 같은 화면으로 이동한다. 상단 **자료 목록**은 모든 화면에서 기존 원문 문서를 열며, **질문·증빙 도구**에서 기존 질문 검토·증거 승인·Bayesian/EIG·예비 심사 내보내기에 접근한다. 원문 상세 패널의 너비와 글자 크기는 공통 형식을 사용한다.

## 검증용 재무팩

`Northstar FDD Lab`은 기존 Northstar 투자 증빙팩과 **별개의 합성 재무팩**이다. 기존 문서에서 추출한 실제 수치로 표시하지 않는다.

- 기간: 2024-01 ~ 2025-12, 기초 NWC: 2023-12.
- 통화·단위: USD 천 달러. 환산 기능은 없으며, 자료 연결 후 단위만 바꿔 같은 숫자를 재표시하지 못한다.
- 월별 관리재무, 시산표, 계정별 원장 월 잔액, 연간 재무제표, 부문 매출, 조정 원장 발췌, 기말 연령, 경영계획을 제공한다.
- 원장은 거래별 전체 분개장이 아닌 **계정별 월 잔액 집계**다. 재무제표도 실제 감사자료가 아니다.
- 2025-12 관리 매출과 시산표의 차이 12, 은행 외부 확인 미수령 등을 의도적으로 포함한다.
- 원천별 SHA256, 버전, CSV 행·열로 추적한다. 다운로드한 CSV 바이트의 해시가 원천 목록과 일치한다.
- 재생성: `python scripts/build_fdd_demo.py`.

2025년 기본 사례의 예상 수치는 매출 14,460, 보고 EBITDA 2,223.40, QoE 조정 +41, 조정 EBITDA 2,264.40, 기말 보고 NWC 307, 조정 NWC 287, 12개월 평균 NWC 280, 순차입금 670, 보고 영업현금흐름 1,840.40, FCF 1,456.40이다.

## 계산·분석 정의

- EBITDA = 매출 − 원가 − 영업비용(D&A 제외). 감가상각비는 별도 항목이다. 기타 비현금 비용은 OCF bridge에서 가산한다.
- QoE = 보고 EBITDA + 해당 월이 선택 기간에 포함되고 **분석 반영**한 조정. 검토 확정·경영진 합의와 별도다.
- NWC = 채권 + 재고 + 기타 영업자산 − 채무 − 기타 영업부채. 현금·차입·리스는 제외한다. 기말 조정을 peg 과거 월에 자동 소급하지 않는다.
- Peg 3/6/12개월 평균은 연속된 해당 월이 모두 있어야 계산한다. 후보값으로 표시하며 자동 합의값으로 취급하지 않는다.
- 순차입금 = 차입 + 리스 − 사용가능 현금 + 기말 debt-like. 제한성 현금은 차감하지 않는다. 거래별 정의 변경은 별도 검토가 필요하다.
- EBITDA → 계산 OCF = EBITDA − 현금 이자 − 현금 세금 − NWC 증가 + 기타 비현금 가산 + 기타 영업현금 영향. 보고 OCF와 대사하고, FCF = 보고 OCF − 유지 CAPEX − 성장 CAPEX로 계산한다.
- Completion accounts 시나리오의 Equity = 입력 EV − 순차입금 + (조정 기말 NWC − 선택 peg). EV 미입력 시 Equity를 산출하지 않는다. QoE를 임의 배수로 가격에 더하지 않는다.
- Locked box 선택 시 이 도구의 NWC 사후 정산은 0이다. 누수·허용 누수·기간 이자 등 계약 세부 조건은 자동 계산하지 않는다.
- 전망은 경영계획이다. 계약 커버리지·매출 환산 공급능력을 표시하며 달성 확률로 해석하지 않는다. 기간 길이가 다르면 성장률 비교를 계산하지 않는다.

원천 숫자는 Decimal로 계산하고 화면 표시에서 반올림한다. 미제공은 `None`, 미정량 쟁점은 빈 금액으로 유지한다. LTM은 연속된 12개월이 필요하며 기간이 끊기면 손익 합계를 계산하지 않는다. 표·차트·내보내기에서 같은 계산 함수를 사용한다.

QoE 워터폴은 작은 조정도 읽을 수 있게 **확대 축**을 명시한다. 표는 금액과 상태에 색을 적용하고 상세 판단은 오른쪽에서 읽는다.

## 작성·검토 경계

자료 **수령**, 조정 **분석 반영**, 조서 **작성 제출**, **검토 기록 확정**, **경영진 합의**를 구분한다. 질문 수·자료 수를 FDD 품질이나 완료율로 쓰지 않는다.

검토 확정 전에는 범위 필수값, 대사 잔여 차이·자료 공백, NWC·순차입금 기준잔액, OCF 대사, 제공된 부문/연령 자료의 합계, 미해결 중요 쟁점·검토 의견, 조정 원천 버전을 확인한다. 중요 쟁점을 범위 제한으로 처리할 때에도 결론을 기록한다. 금액·자료·범위·판단 변경 시 작성 제출·검토 확정을 해제한다.

이름은 **자기기입 기록**으로 계정 인증·권한 분리·독립성을 인증하지 않는다. 회계법인 서명·감사의견·투자 승인이 아니다. 동일 경제적 항목 키 또는 원천 셀을 NWC와 순차입금에 중복 반영하지 못하도록 검사하지만, 서로 다른 이름·자료로 표현된 관련 항목까지 자동 판별하지 않는다.

## 저장·입력·운영 범위

금융 조서는 기존 공식 증빙 엔진과 분리한 서명된 탭 세션이다. 다른 프로젝트·브라우저 세션의 토큰을 사용할 수 없다. 서버에 방문자 DB를 만들지 않으며, 앱 재시작 전 Excel·보고서를 내려받아야 한다. 상단 데모 초기화는 기존 증빙 엔진의 초기화이며, 재무 조서 초기화는 각 FDD 화면 아래에서 별도로 수행한다.

CSV 붙여넣기는 사용자가 직접 입력하는 정형 재무표다. 원천 문서의 OCR·Excel/원장 자동 추출·DART 자동 수집·LLM 분석은 구현한 것으로 표시하지 않는다. 템플릿의 열·순서, 중복 키, 기간, 유한한 금액, 부호, 크기, 원천 행·열을 검증한다. 새 버전 입력 시 이전 원천의 조정 채택·대사·검토를 그대로 이어받지 않는다. 이전 전체 입력 버전을 서버에 영구 보관하는 기능은 없다.

현금흐름 대사를 위한 기초 NWC는 첫 검토 월의 직전 월 자료가 필요하다. 직접 입력하는 CSV에는 해당 기초 월의 채권·재고·기타 영업자산·채무·기타 영업부채를 추가할 수 있다. 기초 월 손익이 없으면 빈칸으로 두고, 실사 범위의 시작 월은 그대로 유지한다.

`기본 재무 조서 다시 시작`은 해당 프로젝트의 초기 합성/빈 조서를 불러온다. `빈 재무 조서로 시작`은 기존 금융 조서를 비우고 직접 입력용 범위를 준비한다. 기존 원문 증빙팩은 바꾸지 않는다.

## 공개 업무 범위 참고

지속 이익, 운전자본, 순차입금·현금흐름, 거래 메커니즘을 중심에 두는 구성은 [PwC 공개 FDD 범위](https://www.pwc.com/us/en/services/consulting/deals/joint-ventures-alliances/financial-due-diligence.html)와 [RSM 공개 FDD 범위](https://www.rsm.global/service/financial-due-diligence)를 참고했다. 특정 회계법인의 비공개 절차나 인증된 FDD 방법론을 재현한 것은 아니다.

## 다음 실행

**실제 코스닥 상장사 1곳을 선정해 공개자료 기반 예비 FDD를 진행한다.** DART 사업·분기보고서, 감사보고서·주석, 공시된 IR 자료로 재무 대사와 분석을 먼저 수행한다. 월별 원장·채권 연령·미공개 계약 등 확보할 수 없는 자료는 미제공·범위 제한으로 남긴다. 상장사와 자료 기준일은 아직 선정하지 않았다.

## 검증 기록 · 2026-11-17

전체 비브라우저 테스트 1,149개와 최종 Chromium 브라우저 시나리오 9개가 통과했다. 마지막 변경의 영향에 대해 웹·스모크 86개, 재무·HTTP 경계 19개를 별도 재검증했다(앞 결과와 중복). 실제 브라우저에서 수정·대사·쟁점 기록·작성/검토·Excel/Markdown 다운로드, CSV 입력·버전 교체·자료 요청 등록, 프로젝트 분리, 390~2560px 화면을 확인했다.

실행 결과와 원천 해시·보호 파일 확인은 `build/fdd-review/verification.json`, `pytest-*.xml`, `screenshots/`에 남겼다. `pip check`, 구문 검사, `git diff --check`도 통과했다. 브랜치는 `feature/korean-ui`이며 commit·push는 수행하지 않았다.
