# Orion 기말과제 구현·시연·검증 안내

## 목적과 구현 경계

PE·IB·Big 4 실무자의 다음 실사 질문 결정을 지원한다. 5단계는 자료 분석 → 가설 검토 → 질문 구성 → 중요도 평가 → 새 증거 반영이다. 회계법인 FDD 전체 자동화나 투자수익 예측을 주장하지 않는다.

현재 앱은 Python 3.12/Flask, HTML/CSS/JavaScript, SQLite, pypdf/python-docx/python-pptx/openpyxl을 사용한다. 검색은 한국어 부분 토큰·금융 동의어를 포함한 로컬 BM25이며, 질문은 검토 가능한 규칙·템플릿으로 구성한다. 외부 LLM·유료 API·벡터 DB는 사용하지 않는다. 기존 Dash/Plotly 앱은 `--legacy`로 별도 실행한다.

### 자료와 근거

문서의 기재 내용, 검토자의 해석, 계산 가정을 별도로 보관한다. 기본 3개 점검 과제는 관련 근거가 없을 때 '기본 점검 과제 · 근거 미검출'로 표시한다. 검색 일치는 사실 검증이 아니며, 사례 팩의 사전 작성 질문은 일반 문서에서 자동 발견한 질문과 구분한다. 원문 해시는 추출문 변형 확인용이지 내용의 진실성 보증이 아니다.

### Excel과 재무 관측치

일반 XLSX 파일을 업로드할 수 있다. 시트·셀 주소·원래 값·수식·저장된 계산값·표시 형식·숨김 시트 여부를 보존한다. 수식과 외부 링크는 실행하지 않는다. 계산값이 없거나 Excel 오류이면 경고하며 숫자를 발명하지 않는다.

자동 구조화 입력의 열은 **항목, 값, 단위, 기간, 범위, 구분**이다. 1단계에서 합성 Excel 입력 양식을 내려받을 수 있다. 복잡한 기존 모델은 원문 구간에서 숫자 셀을 선택하고 '이 셀을 재무 관측치로 등록'한 뒤 해석을 입력한다. 자유 텍스트의 모든 숫자를 임의로 재무 항목으로 확정하지 않는다.

관측치 검토 시 항목·단위·기간·범위·실적/계획·검토 근거를 입력한다. 둘 다 검토한 서로 다른 문서에서 같은 항목·기간·범위·구분·통화인 값만 비교한다. 원/천원/백만원/억원을 환산하되 실적과 계획, 별도와 연결, 다른 기간은 비교하지 않는다. 차이는 원인 미판정이며 회계 오류나 조정액으로 단정하지 않는다. 조건을 수정하면 오래된 차이 질문은 활성 추천에서 제외한다.

Excel 한도: 30개 시트, 시트당 5만 셀 영역, 전체 5만 비어 있지 않은 셀, ZIP 확장 64MB. 파일은 10MB, 추출은 40초 제한이다. OCR·범용 표 이해·Excel 재계산 엔진은 포함하지 않는다.

### 계산과 설명

Bayesian: P(H|E)=P(E|H)P(H) / [P(E|H)P(H)+P(E|not H)(1-P(H))]. 지지·반박은 담당자 판정이며, 불충분·반려·독립성 미확인 증거는 확률을 억지로 바꾸지 않는다. 동일 원문이나 의존 그룹의 중복 반영을 방지한다.

EIG는 가능한 답변에 대한 평균 엔트로피 감소(bits)다. EVSI는 답변별 최선 행동의 기대효용에서 현재 최선 행동의 기대효용을 뺀 값이다. 순효용은 EVSI에서 확보·지연 비용을 차감한다. 효용 단위·척도가 다른 값과 EIG는 합산하지 않는다. 동일 단위·출처도 공통 효용 기준인지 검토가 필요하다.

추천은 필수 질문 우선 후 중요도 35%·증빙 공백 25%·EIG 25%·확보 가능성 15%다. EIG 미설정 시 정성 가중치를 재정규화한다. 중요도 1~5 평가 설명과 증빙 공백 분류를 제공한다. 분류를 검토한 질문의 공백 점수는 `min(1,0.4+0.15×분류 수)`인 공개된 휴리스틱이다. 구버전·미검토 질문은 기존 공백 점수(대기 0.8/보완 1)를 유지한다. 이는 실증적으로 최적화한 정책이 아니다.

4단계의 계산 과정에서는 답변 발생 확률·사후확률·최선 행동·효용을 확인하고, 사전확률 0.1~0.9, 다음 질문 우도 차이 ±0.1, 비용 0.5/2배를 비교한다. 실제 저장 상태는 변경하지 않는다. 사전확률 변경은 승인된 증거를 재생하고 우도 변화는 다음 질문 평가에만 적용한다. 과거 증거의 적용 당시 우도는 유지한다.

새 스냅샷은 효용표·비용·우도·사전확률·질문 점수·EVSI·재무 관측치·증거를 보관한다. 구버전에 없던 가정은 소급 생성하지 않는다. 적용 전 미리보기에서 확률·우도비·EIG·EVSI·추천 전후 변화를 확인한다.

## 재현 실행

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install --require-hashes -r requirements-win.lock
.\.venv\Scripts\python -m pip install --no-deps --no-build-isolation -e .
.\.venv\Scripts\python -m orion.app
```

Linux는 `requirements-linux.lock`, `.venv/bin/python`을 사용한다. 로컬 `http://127.0.0.1:8050`에 접속한다. 실제 딜 사례 없이도 합성 검증 사례·합성 Excel 양식·정책 비교 실험을 실행할 수 있다. `.local/`의 실제 자료·DB·익명화 팩은 Git에 포함하지 않는다.

## 5~7분 시연

1. '합성 검증 사례 열기': 공개 가능한 합성 자료라는 표시와 5단계 설명.
2. 1단계: 원문 검색·해시·자료 처리 범위. Excel 입력 양식과 검토 전/후 대사 제한 설명.
3. 2~3단계: 가설·반대 가설, 관측 사실·검증 공백·질문 근거 연결 확인.
4. 4단계: EIG·EVSI 차이, 비용 전/후, `recurring.definition` 계산 과정. 확률 0.3, 우도 0.8/0.2, 효용 100/-100이면 지지 후 약 63.16%, EIG 약 0.2361 bits, EVSI 10점, 비용 5점 차감 후 5점.
5. 민감도·정책 비교와 합성 실험을 실행. 독립 평가와 실제 기업 성능은 미검증임을 설명.
6. 5단계: 지지/반박/불충분 답변을 미리보기하고 승인 후 확률·후속 질문·추천 변화 확인. 철회하면 재생.
7. 검토 보고서 HTML을 내려받아 브라우저 인쇄로 PDF 저장. 질문 CSV·검토 JSON도 확인.

## 효과 평가와 한계

```powershell
.\.venv\Scripts\python scripts/evaluate_rules_mvp.py
.\.venv\Scripts\python -m pytest tests/rules -q
```

`build/rules-mvp-evaluation/`에 입력·소스 SHA-256을 포함한 JSON, 정책 비교 CSV, 빈 독립 검토 양식을 만든다. 합성 사례 3개×정책 4개를 같은 5개 후보·질문 3개·총 15분 가정으로 비교한다. 평가용 중요도 정답은 추천 엔진에 전달하지 않는다. 고정 순서·정성 중요도·Bayesian/EIG·EVSI/비용의 핵심 질문 포함률, nDCG@3, 첫 질문 순효용과 답변 후 확률을 공개한다.

이는 작성자가 구성한 작은 통제 실험이다. 독립 검토, 미사용 실제 자료 검증, 의미적 근거 적합성, 실무 시간 절감과 투자성과는 **미실행/미측정**이다. 근거 ID 연결률은 의미적 정확도가 아니다. 교차 문서 원인 추론이나 스캔 OCR은 포함하지 않는다. 학습 모델 정확도·Brier score·보정 성능을 이 결과로 주장하지 않는다. 타인 검토 시 질문·근거 적합성 0~2, 요청 자료·판정 기준 실행 가능성 0~2, 핵심 질문 여부를 정책명을 가리고 평가하도록 권장한다.

기존 `evaluation/results`는 별도의 과거 합성 실험이다. 현재 MVP 평가와 섞지 않는다. 테스트 통과 수는 소프트웨어 검증 결과이며 금융 분석 성능이 아니다.
